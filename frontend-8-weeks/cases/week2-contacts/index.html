Week 2 · 增删查

📇 通讯录 CRUD

用函数封装数组的增删查列操作,体会 some / filter / includes 各自适合的场景。

📇本案例的结果全部在控制台:按 F12 打开开发者工具,切到 Console 面板查看演示输出。

  • 增add —— 先用 some 查重,重名拒绝,否则 push
  • 删remove —— filter 留下"不等于该名字"的新数组
  • 查search —— 字符串 includes 做模糊匹配
  • 列list —— forEach 带下标打印全部联系人

脚本末尾自带一段演示调用(含重名添加、删除不存在的人等失败分支),刷新页面即可重新运行。
