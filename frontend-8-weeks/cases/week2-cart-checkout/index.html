Week 2 · 数组方法

🛒 购物车结算

用 map / filter / reduce 处理商品数组:算选中总价、满减实付,再拼一张购物小票。

🛒本案例的结果全部在控制台:按 F12 打开开发者工具,切到 Console 面板查看输出。

  1. 选中商品总价 —— filter 挑勾选项 + reduce 累加
  2. 满 300 减 50 的实付金额 —— 三元表达式
  3. 单价大于 100 的商品 —— filter + console.table
  4. 购物小票字符串 —— map 转行文字 + join 拼接

刷新页面即可重新运行脚本;数据内置在 script 里,可自行改价格 / 勾选状态观察输出变化。
